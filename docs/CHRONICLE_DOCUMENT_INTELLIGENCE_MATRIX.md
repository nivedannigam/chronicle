## Canonical pipeline (target)

```
Google Drive → Download → Detect type → Native text (if PDF) → AI understanding → Structured facts → Evidence → Canonical record → Knowledge → Library / Search / Ask
                                                                 ↓ (if insufficient)
                                                               OCR → AI understanding
```

OCR is **not** the default when embedded PDF text is usable.
